# シフト管理システム

## 概要
店長がスタッフのシフトを管理し、
スタッフが自分のシフトを簡単に確認できるシステムです。

Javaのコンソール上で動作します。

## 作成した目的
アルバイトのシフトを簡単に確認できるようにすることと、
店長がスタッフのシフトを管理しやすくすることを目的として作成しました。

## 主な機能

### スタッフ
- ログイン
- スタッフ情報の確認
- 自分のシフト確認
- シフト詳細の確認

### 店長
- ログイン
- スタッフ情報の確認
- スタッフ追加
- スタッフ検索
- スタッフ削除
- シフト追加
- シフト変更
- シフト削除
- 店舗情報の確認

## 使用技術
- Java
- Eclipse
- Git
- GitHub
- ArrayList

## クラス
### Main.java
ログインやメニュー表示、シフト管理などの処理を行います。

### Staff.java
スタッフのID、名前、メールアドレス、パスワード、役割を管理します。

### Shift.java
シフトの勤務日、開始時間、終了時間などを管理します。

### Store.java
店舗名や住所などの店舗情報を管理します。

## 実行方法
EclipseでMain.javaを開き、
「Run As → Java Application」で実行します。
